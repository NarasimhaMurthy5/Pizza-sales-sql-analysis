# 🍕 Pizza Sales Data Analysis (SQL Project)

## 📌 Overview
This project focuses on analyzing pizza sales data using SQL to extract meaningful business insights.  
The analysis helps understand customer behavior, sales performance, and revenue trends.

---

## 🎯 Objective
- Analyze sales data to identify top-performing products  
- Understand customer ordering patterns  
- Find peak sales hours and trends  
- Generate insights to support business decisions  

---

## 📂 Dataset Description
The dataset consists of 4 tables:

- **orders** → Contains order date and time  
- **order_details** → Contains order quantity and pizza IDs  
- **pizzas** → Contains pizza size and pricing  
- **pizza_types** → Contains pizza name, category, and ingredients  

---

## 🛠️ Tools & Technologies Used
- SQL (MySQL / PostgreSQL)
- Relational Database Concepts

---

## 🧠 Key SQL Concepts Used
- JOINs (INNER JOIN)
- Aggregate Functions (SUM, COUNT, AVG)
- GROUP BY & ORDER BY
- Subqueries
- Window Functions (RANK)
- Data Filtering

---

## 📊 Key Analysis Performed

1. Total Revenue Calculation  
2. Total Orders & Average Order Value  
3. Top 5 Best-Selling Pizzas  
4. Revenue by Pizza Category  
5. Peak Order Hours  
6. Daily Order Trends  
7. Most Popular Pizza Sizes  
8. Ranking of Pizzas by Sales  

---

## 💡 Key Insights

- Certain pizza categories generate higher revenue than others  
- Peak order hours occur during specific time periods (lunch/dinner)  
- A small number of pizzas contribute to a large portion of total sales  
- Medium and Large sizes are more frequently ordered
